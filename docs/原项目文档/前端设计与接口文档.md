# AgentForge 前端设计与接口文档

> 版本：v0.1  
> 配套后端：Java `platform-api` + Python `agent-runtime`  
> 覆盖阶段：M1 / M2 / M3 / M4  
> 说明：原始开发文档只定义了 M1/M2/M3，M4 为扩展规划，代表生产化、多租户和规模化能力。

---

## 0. 前端整体定位

前端是 AgentForge 的工作台，不是普通聊天页面。

它需要支持：

- 项目与知识库管理
- 会话与消息
- SSE 流式对话
- 引用来源展示
- Agent 执行步骤时间线
- Trace 调用链
- 任务与审批
- 评估与指标
- Prompt / 模型 / 工具管理
- 内容生成
- 权限与审计

技术栈建议：

```text
React
TypeScript
Vite
React Router
TanStack Query
Zustand 或 Redux Toolkit
Ant Design 或 shadcn/ui
Monaco Editor
ECharts 或 Recharts
SSE / fetch ReadableStream
```

## 1. 后端基础约定

### 1.1 服务地址

```text
Java platform-api: http://localhost:8080
Python agent-runtime: http://localhost:8000
```

前端只直接访问 Java `platform-api`，不建议直接访问 Python。

### 1.2 统一返回结构

```json
{
  "code": 0,
  "message": "success",
  "data": {}
}
```

错误：

```json
{
  "code": 40000,
  "message": "参数错误",
  "data": null
}
```

### 1.3 错误码建议

```text
0       成功
40000   参数错误 / 业务校验失败
40400   资源不存在
50000   系统内部错误
```

### 聊天

```http
POST /api/chat

```

请求：

```json
{
  "projectId": 1,
  "conversationId": 1,
  "message": "ProjectService 这个类的代码在哪里？",
  "showCitations": true
}
```

普通响应：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "userMessageId": 10,
    "assistantMessageId": 11,
    "content": "我在 ...ProjectService.java:20 找到了相关代码。",
    "citations": [
      {
        "sourceType": "code",
        "file": "platform-api/src/main/java/com/agentforge/platform/service/ProjectService.java",
        "line": 20,
        "snippet": "@Service\n@AllArgsConstructor\npublic class ProjectService {"
      }
    ],
    "traceId": "trace-xxx",
    "promptTokens": 0,
    "completionTokens": 0,
    "totalTokens": 0,
    "latencyMs": 25
  }
}
```

### SSE 事件

```text
event: route
data: {"agent":"code_agent"}

event: step
data: {"type":"tool_call","tool":"search_code","args":{"query":"ProjectService 这个类的代码在哪里？"}}

event: answer
data: {"content":"...","citations":[...]}

event: done
data: {"traceId":"trace-xxx","usage":{...}}
```

## 9. SSE 前端处理建议

因为 `EventSource` 只支持 GET，而聊天是 POST，所以使用：

```ts
fetch("/api/chat/stream", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
  },
  body: JSON.stringify(payload),
})
```

然后读取：

```ts
const reader = response.body.getReader();
```

按 SSE 格式解析：

```text
event:route
data:{...}

event:step
data:{...}

event:answer
data:{...}

event:done
data:{...}
```
