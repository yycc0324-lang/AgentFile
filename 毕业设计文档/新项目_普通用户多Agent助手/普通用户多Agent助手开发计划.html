一、项目定位与目标用户

本项目是一个面向普通用户的多 Agent 协作智能助手。用户不需要懂代码，只需要提出目标、上传文档或描述需要研究的问题，系统自动完成任务拆解、资料检索、文档阅读、证据核查和结果写作。

一句话定位：用户说出目标，多个 Agent 分工完成，最后给出清晰、可靠、可追溯的答案或报告。

系统采用 Vue 3 前端 + Java Spring Boot 平台 + Python FastAPI 多 Agent Runtime + MySQL + Qdrant + 文档/搜索工具的分层架构。Java 负责平台治理和持久化，Python 负责多 Agent 编排与工具执行。

八、M1-M4 迭代路线

8.1 M1：基础平台与单 Agent MVP

目标：完成用户可用最小闭环：任务创建、文本输入、单 Agent 回答、SSE 展示、消息历史和基础 Trace。

项目/任务/会话/消息基础 API；

Vue 3 场景入口与聊天页；

Python FastAPI 单 Agent Runtime；

基础工具：文档解析、search_documents、read_file；

SSE 推送 route / step / answer / done；

Task / TaskStep / TraceSpan 记录。

8.2 M2：多 Agent 协作运行时

目标：从单 Agent 升级为 Coordinator + Planner + Research/Reader/Reviewer/Writer 的多 Agent 协作。

实现 Coordinator 任务分解与调度；

实现 Blackboard 共享上下文和结构化 Agent 消息；

实现 Planner / Research / Reader / Reviewer / Writer 角色；

完成学习规划、文档理解、报告生成三个核心场景；

前端展示 Agent 执行链和结果。

8.3 M3：增强场景与检索评估

目标：增加信息核查、生活决策、编程入门和 RAG 检索评估。

文档上传、解析、Embedding、Qdrant 混合检索；

Web Search / 来源引用 / 信息核查；

生活决策低风险模板；

Tutor Agent 编程入门模式；

20+ 评估集、人工评分和 Trace 回放。

8.4 M4：产品化与安全治理

目标：面向真实普通用户产品化。

用户登录、权限、配额；

敏感内容与高风险话题安全策略；

多轮记忆和个性化偏好；

监控、成本统计、部署与灰度；

多租户/插件/运营后台等扩展。

十一、评估计划

评估分为四类：答案正确性、证据引用质量、任务步骤效率和 Agent 协作有效性。M1 先建立 20 条基础样例；M2 增加多 Agent 任务成功率和步骤合理性；M3 增加信息核查与文档理解的引用准确性评估。

指标

说明

答案正确性

最终回答是否符合问题要求

引用准确性

引用是否支持结论、来源是否真实

工具调用正确率

是否调用了正确工具和参数

任务成功率

多 Agent 是否完成任务

步骤效率

是否出现重复检索、无效工具调用

用户可读性

输出是否清晰、结构是否合理

十二、风险与对策

风险

对策

限制高风险话题，增加证据和风险提示

先支持 PDF/Markdown/TXT，逐步增加格式
